# Sleep Tracking Module 

## Модуль отслеживания сна

Этот модуль обеспечивает комплексное отслеживание сна с интеллектуальными уведомлениями и виджетами в шторке уведомлений.

### Функциональность

#### 🌙 Виджет отслеживания сна
- **Автоматические уведомления** за 30 минут до рекомендованного времени сна
- **Интерактивный виджет** в шторке уведомлений с кнопками действий
- **Отслеживание сессий сна** от засыпания до пробуждения
- **Минимальное энергопотребление** благодаря оптимизированным алгоритмам

#### 📅 Управление расписанием сна
- Настройка времени пробуждения по дням недели
- Три режима расписания:
  - Одинаковое время каждый день (рекомендуется)
  - Отдельно будни и выходные
  - Индивидуальное время для каждого дня
- Автоматический расчет времени засыпания (8 часов сна по умолчанию)

#### 📊 Аналитика сна
- Просмотр данных сна по дням
- Общая продолжительность сна за день
- Детализация по сессиям сна
- Редактирование и удаление периодов сна

### Компоненты

#### SleepNotificationService
Управляет уведомлениями и виджетами в шторке:
- **Энергоэффективность**: отключен звук, вибрация и световые индикаторы
- **Persistent виджеты**: виджеты остаются в шторке до завершения действия
- **Обработка действий**: автоматическое создание и завершение сессий сна

#### SleepBackgroundService  
Фоновое отслеживание времени:
- **Минимальная частота проверки**: раз в 15 минут для экономии батареи
- **Работа без интернета**: кэширование расписания для автономной работы
- **Умные ограничения**: работает даже при низком заряде батареи

#### SleepTrackingWidget
UI для управления отслеживанием:
- **Визуальная обратная связь** о состоянии отслеживания
- **Информация о текущей сессии** сна
- **Кнопки управления** с интуитивным интерфейсом

### Оптимизации производительности

#### Энергопотребление
- Использование `workmanager` вместо постоянных фоновых процессов
- Отключение звуков, вибрации и светодиодов в уведомлениях
- Минимальная частота проверки (15 минут)
- Кэширование данных для работы без сети

#### Память и производительность  
- `RepaintBoundary` для изоляции перерисовок виджетов
- Кэширование данных сна с проверкой актуальности
- Ленивая загрузка данных по датам
- Debounce для предотвращения частых запросов

### Workflow пользователя

1. **Настройка расписания**
   - Пользователь настраивает время пробуждения в разделе "Сон"
   - Включает отслеживание сна

2. **Автоматическое уведомление**
   - За 30 минут до рекомендованного времени сна появляется виджет "Пора спать!"
   - Показывается рекомендованное время засыпания
   - Доступна кнопка "Ложусь спать"

3. **Начало сна**
   - При нажатии "Ложусь спать" создается новая сессия сна
   - Виджет меняется на "Спокойной ночи!" 
   - Показывается время пробуждения
   - Доступна кнопка "Я проснулся"

4. **Завершение сна**
   - При нажатии "Я проснулся" сессия сна завершается
   - Данные сохраняются в базе данных
   - Виджет исчезает из шторки уведомлений

### API Integration

Модуль интегрируется с `sleep-service` backend:
- `POST /sleep` - создание сессии сна
- `PUT /sleep/:id/wake-up` - быстрое завершение сессии
- `GET /sleep/schedule` - получение расписания
- `POST /sleep/schedule` - создание/обновление расписания
