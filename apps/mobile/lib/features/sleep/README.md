# Модуль Sleep (Сон)

Модуль для управления расписанием сна и записями о сне пользователя.

## Структура

```
sleep/
├── README.md                          # Документация модуля
├── sleep_screen.dart                  # Основной экран управления сном
├── screens/                           # Экраны модуля
│   └── sleep_schedule_edit_screen.dart  # Экран редактирования расписания
├── models/                            # Модели данных
│   ├── sleep_session_model.dart
│   └── sleep_schedule_model.dart
├── services/                          # Сервисы для работы с API
│   └── sleep_service.dart
└── widgets/                           # Виджеты компонентов
    ├── sleep_schedule_settings.dart     # Настройки расписания
    └── next_wake_time_display.dart      # Отображение времени пробуждения
```

## Основные компоненты

### SleepScreen
Главный экран модуля, который:
- **Адаптивный интерфейс**: Показывает время завтрашнего пробуждения если расписание настроено, или форму настройки если не настроено
- Отображает информацию о планируемом времени пробуждения
- Предоставляет кнопку для редактирования расписания
- Показывает fallback режим при недоступности сервиса
- Обеспечивает graceful degradation при ошибках подключения

### SleepScheduleEditScreen
Отдельный экран для редактирования расписания сна:
- Полноэкранный интерфейс для настройки расписания
- Использует тот же дизайн что и встроенные настройки
- Автоматически возвращается на главный экран после сохранения
- Показывает информационные подсказки пользователю

### NextWakeTimeDisplay
Виджет для отображения планируемого времени пробуждения:
- **Рекомендуемое время засыпания**: Основной блок с крупным временем (36px) в фиолетовом дизайне
- **Время пробуждения**: Компактный блок с информацией о завтрашнем пробуждении
- **Персонализация**: Использует индивидуальную рекомендуемую продолжительность сна из профиля пользователя
- **Обработка overflow**: Использует Flexible и Expanded для предотвращения ошибок переполнения
- **Кнопка редактирования**: В правом верхнем углу для перехода к настройкам
- **Адаптивность**: Корректно работает со всеми типами расписаний и отключенным режимом

### SleepService
Сервис для взаимодействия с sleep-service API:
- **URL конфигурация**: Автоматически использует `10.0.2.2:3003` для Android эмулятора и `localhost:3003` для других платформ
- **Управление расписанием**: CRUD операции с расписанием сна
- **Проверка доступности**: Быстрая проверка доступности сервиса
- **Обработка ошибок**: Graceful fallback при недоступности сервиса

### Модели данных
- **SleepSchedule**: Модель расписания сна с поддержкой разных типов (ежедневно, будни/выходные, индивидуально)
  - Корректный парсинг типов расписания с сервера
  - Метод `getWakeTimeForDay()` для получения времени пробуждения на конкретный день
- **SleepSession**: Модель сессии сна для записи периодов сна

## Особенности

### Адаптивный пользовательский интерфейс
- **Умное отображение**: Показывает время пробуждения если расписание настроено, форму настройки если не настроено
- **Интуитивная навигация**: Кнопки редактирования ведут на отдельный экран настроек
- **Персонализированные рекомендации**: Автоматически рассчитывает время засыпания на основе профиля пользователя
- **Информативность**: Отображает день недели, время пробуждения и рекомендуемое время засыпания

### Поддержка платформ
Модуль автоматически определяет платформу и использует правильные URL:
- **Android эмулятор**: `http://10.0.2.2:3003/sleep`
- **Другие платформы**: `http://localhost:3003/sleep`

### Graceful Degradation
При недоступности sleep-service:
- Показывается информационное уведомление
- Интерфейс остается функциональным
- Предоставляется возможность повторной попытки подключения
- Нет блокирующих ошибок

### Типы расписания
- **DAILY**: Одинаковое время пробуждения каждый день
- **WEEKDAYS_WEEKENDS**: Разное время для будней и выходных
- **INDIVIDUAL**: Индивидуальное время для каждого дня недели

## API Integration

Модуль интегрируется с sleep-service микросервисом:
- **GET /sleep/schedule** - получение расписания
- **POST /sleep/schedule** - создание расписания
- **PUT /sleep/schedule** - обновление расписания
- **DELETE /sleep/schedule** - удаление расписания
- **GET /sleep/schedule/wake-time** - получение времени пробуждения для даты

Все запросы требуют заголовок `user-id` для идентификации пользователя.
