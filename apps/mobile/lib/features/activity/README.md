# Activity Module - Модуль отслеживания физической активности

## Описание

Модуль Activity предоставляет полнофункциональную систему отслеживания тренировок и физической активности пользователя с автоматическими расчетами и inline-редактированием подходов.

## Основные возможности

### 🏋️ Управление тренировками
- **Создание тренировок** - быстрое создание тренировок с указанием даты
- **Навигация по датам** - просмотр тренировок за любую дату с удобной навигацией
- **Статистика в реальном времени** - автоматический расчет общего веса, количества упражнений и тренировок
- **⏱️ Таймер тренировок** - отслеживание времени выполнения тренировки в режиме реального времени
- **📅 Расписание тренировок** - настройка еженедельного расписания с выбором групп мышц для каждого дня

### 💪 Упражнения
- **База упражнений** - обширная база упражнений с группами мышц
- **Поиск и фильтрация** - быстрый поиск упражнений по названию и фильтрация по группам мышц
- **Добавление в тренировку** - множественный выбор упражнений для добавления
- **Удаление из тренировки** - возможность удалить упражнение и все его подходы с подтверждением
- **Спойлер-интерфейс** - компактное отображение с возможностью разворота только одного упражнения
- **Отображение названий и групп мышц** - корректное отображение информации об упражнениях

### 🎯 Подходы (Sets)
- **Inline-редактирование** - редактирование подходов прямо на экране тренировки без дополнительных переходов
- **Автоматическое сохранение** - изменения сохраняются автоматически через 1.5 секунды после ввода с debounce механизмом
- **Мгновенная отзывчивость UI** - локальное обновление состояния для немедленной визуальной обратной связи
- **Добавление/удаление подходов** - простое управление подходами с подтверждением удаления
- **Автоматический расчет** - расчет общего веса: `повторения × вес × количество снарядов`
- **Валидация ввода** - защита от некорректных значений с использованием input formatters
- **Визуальные индикаторы сохранения** - цветовые индикаторы и анимация процесса сохранения
- **Обработка ошибок** - уведомления об ошибках с возможностью повторной попытки

## Ключевые улучшения

### ✅ Исправленные проблемы

#### 1. **Отображение названий упражнений**
- **Проблема**: Отображались заглушки "Неизвестное упражнение", "Неизвестная группа"
- **Решение**: Улучшена обработка JSON с поддержкой вложенных объектов `exercise`
```dart
exerciseName: json['exercise']?['name'] as String? ?? 
             json['exerciseName'] as String? ?? 
             'Неизвестное упражнение',
```

#### 2. **Ошибки типов данных**
- **Проблема**: Ошибка "type 'String' is not a subtype of type 'num'"
- **Решение**: Добавлена безопасная обработка типов для всех числовых полей
```dart
weight: json['weight'] is String 
    ? double.tryParse(json['weight'] as String) ?? 0.0
    : (json['weight'] as num?)?.toDouble() ?? 0.0,
```

#### 3. **Обновление списка тренировок**
- **Проблема**: Список не обновлялся после возвращения с экрана тренировки
- **Решение**: Принудительная очистка кэша и перезагрузка данных
```dart
if (result == true || result == null) {
  _cachedWorkouts = null;
  await _activityService.clearCache();
  await _loadWorkoutsForDate(_selectedDate);
}
```

#### 4. **Редактирование подходов**
- **Проблема**: Ошибки при редактировании веса и необходимость перехода на отдельный экран
- **Решение**: Реализовано inline-редактирование с автоматическим сохранением прямо на экране тренировки

### 🆕 Новая функциональность

#### ⏱️ Таймер тренировок

**Как это работает:**
1. **Создание тренировки** - при создании тренировки она появляется с нулевой продолжительностью
2. **Начало тренировки** - нажатие кнопки "Начать тренировку" запускает таймер
3. **Активный таймер** - отображается в формате чч:мм:сс, работает даже при переходе между экранами
4. **Завершение тренировки** - нажатие кнопки "Завершить тренировку" останавливает таймер и сохраняет время
5. **Глобальная видимость** - активный таймер отображается поверх всех экранов приложения

**Особенности реализации:**
- **Оптимизация производительности**: использование RepaintBoundary и оптимизированных таймеров
- **Глобальное состояние**: WorkoutTimerService как синглтон с ChangeNotifier
- **Персистентность**: таймер продолжает работать при переходе между экранами
- **Автовосстановление**: при перезапуске приложения активная тренировка восстанавливается
- **Единственная активная тренировка**: невозможно запустить несколько таймеров одновременно

#### Автоматическое сохранение подходов
- **Прямое редактирование** на экране тренировки без дополнительных переходов
- **Debounce механизм** - сохранение через 1.5 секунды после прекращения ввода для оптимизации запросов
- **Мгновенное обновление UI** - локальное состояние обновляется немедленно для отзывчивости
- **Индивидуальные таймеры** - каждый подход имеет свой таймер автосохранения
- **Визуальные индикаторы** - анимация загрузки и изменение цвета во время сохранения
- **Валидация ввода** с использованием `FilteringTextInputFormatter`
- **Обработка ошибок** с возможностью повторной попытки
- **Принудительное сохранение** при уходе с экрана

#### 📅 Расписание тренировок

**Как это работает:**
1. **Доступ к настройкам** - кнопка шестеренки в блоке статистики на главном экране
2. **Настройка дней** - выбор дней недели для тренировок простым переключателем
3. **Выбор типа тренировки** - для каждого дня можно выбрать fullbody или конкретную группу мышц
4. **Автоматическое сохранение** - изменения сохраняются сразу при клике без отдельной кнопки "Сохранить"
5. **Отображение в статистике** - информация о сегодняшней тренировке показывается на главном экране

**Особенности реализации:**
- **Группы мышц**: Ноги, Спина, Бицепс, Плечи, Трицепс (автоматически заполняются при первом запуске)
- **Мгновенная отзывчивость UI**: локальное обновление состояния для быстрой обратной связи
- **Обработка ошибок**: откат изменений в случае ошибки сохранения на сервере
- **Оптимизация производительности**: RepaintBoundary для каждого дня недели
- **Интуитивный интерфейс**: переключатели, чипы для групп мышц, цветовые индикаторы

## API интеграция

### Основные эндпоинты

#### Базовые операции с тренировками
- `GET /workouts/by-date?date=YYYY-MM-DD` - получение тренировок по дате
- `POST /workouts` - создание новой тренировки
- `GET /workout-exercises/by-workout/{workoutId}` - получение упражнений тренировки
- `POST /workout-exercises` - добавление упражнения в тренировку
- `DELETE /workout-exercises/{workoutExerciseId}` - удаление упражнения из тренировки
- `POST /sets` - создание подхода
- `PUT /sets/{setId}` - обновление подхода
- `DELETE /sets/{setId}` - удаление подхода
- `POST /sets/bulk/{workoutExerciseId}` - массовое создание подходов

#### ⏱️ Эндпоинты таймера
- `POST /workouts/{id}/start` - начало тренировки (запуск таймера)
- `POST /workouts/{id}/finish` - завершение тренировки (остановка таймера)
- `GET /workouts/active/current` - получение активной тренировки пользователя

#### Новые поля в модели Workout
- `startedAt` - время начала тренировки (для таймера)
- `finishedAt` - время завершения тренировки (для таймера)  
- `isActive` - флаг активности тренировки

#### 📅 Эндпоинты расписания тренировок
- `GET /muscle-groups` - получение всех групп мышц
- `GET /workout-schedule/user/{userId}` - получение расписания пользователя на всю неделю
- `GET /workout-schedule/user/{userId}/today` - получение тренировки на сегодня
- `PUT /workout-schedule/user/{userId}/day/{dayOfWeek}` - создание/обновление расписания для дня
- `DELETE /workout-schedule/user/{userId}/day/{dayOfWeek}` - удаление расписания для дня (день отдыха)

### Обработка ошибок
- **Retry логика** - автоматические повторные попытки при сетевых ошибках
- **Кэширование** - TTL кэш для минимизации запросов к серверу
- **Graceful degradation** - корректная обработка отсутствующих данных

## Производительность

### Оптимизации
- **RepaintBoundary** для изоляции перерисовок отдельных элементов
- **Кэширование данных** с TTL для минимизации сетевых запросов
- **Debounce** для предотвращения частых обновлений при редактировании
- **Lazy loading** упражнений с пагинацией
- **Connection pooling** для HTTP клиента

### Мониторинг
- Логирование времени выполнения операций
- Отслеживание ошибок сети и их обработка
- Мониторинг производительности UI с использованием `PerformanceMonitorMixin`

## Использование

### Создание тренировки
```dart
// Создание тренировки
final workout = await activityService.createWorkout(
  date: DateTime.now(),
);

// Добавление упражнения
await activityService.addExerciseToWorkout(
  workout.id, 
  exerciseId
);

// Создание подхода
await activityService.createSet(
  workoutExerciseId: exercise.id,
  reps: 10,
  weight: 50.0,
);
```

### Inline-редактирование подхода
```dart
// Обновление подхода
await activityService.updateSet(
  setId: set.id,
  reps: newReps,
  weight: newWeight,
);
```

## Типы данных

### WorkoutSet (Подход)
```dart
class WorkoutSet {
  final String id;
  final String workoutExerciseId;
  final int reps;              // Количество повторений
  final double weight;         // Вес снаряда
  final double totalWeight;    // Общий поднятый вес
}
```

### WorkoutExercise (Упражнение в тренировке)
```dart
class WorkoutExercise {
  final String id;
  final String exerciseId;
  final String exerciseName;        // Название упражнения
  final String targetMuscleGroup;   // Целевая группа мышц
  final int equipmentCount;         // Количество снарядов
  final List<WorkoutSet> sets;      // Подходы
}
```

### Workout (Тренировка)
```dart
class Workout {
  final String id;
  final DateTime date;
  final int? duration;                      // Продолжительность в минутах
  final List<String> targetMuscleGroups;   // Целевые группы мышц
  final double totalWeight;                // Общий поднятый вес
  final List<WorkoutExercise> exercises;   // Упражнения
  final DateTime? startedAt;               // Время начала тренировки (для таймера)
  final DateTime? finishedAt;              // Время завершения тренировки (для таймера)
  final bool isActive;                     // Активна ли тренировка (идет таймер)
}
```

### MuscleGroup (Группа мышц)
```dart
class MuscleGroup {
  final String id;
  final String name;          // Название группы мышц
  final String? description;  // Описание группы мышц
}
```

### WorkoutSchedule (Расписание тренировок)
```dart
class WorkoutSchedule {
  final String id;
  final String userId;
  final int dayOfWeek;        // День недели (0=воскресенье, 1=понедельник, ..., 6=суббота)
  final String? muscleGroupId; // ID группы мышц
  final bool isFullBody;      // Флаг fullbody тренировки
  final bool isActive;        // Активно ли расписание для этого дня
  final MuscleGroup? muscleGroup; // Связанная группа мышц
}
```
