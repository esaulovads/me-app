# Модуль отслеживания физической активности

Этот модуль обеспечивает полную функциональность отслеживания тренировок в мобильном приложении.

## Структура модуля

```
activity/
├── models/                     # Модели данных
│   ├── exercise_model.dart     # Модель упражнения
│   └── workout_model.dart      # Модели тренировки, упражнения в тренировке, подхода
├── services/                   # Сервисы
│   └── activity_service.dart   # Сервис для работы с API активности
├── widgets/                    # Виджеты
│   └── activity_progress_bar.dart # Прогресс-бар активности для главного экрана
├── screens/                    # Экраны
│   ├── create_workout_screen.dart      # Создание новой тренировки
│   ├── exercise_selection_screen.dart  # Выбор упражнений для добавления в тренировку
│   ├── exercise_sets_screen.dart       # Управление подходами упражнения
│   └── workout_detail_screen.dart      # Детализация тренировки
├── activity_screen.dart        # Основной экран активности
└── README.md                   # Этот файл
```

## Основные функции

### 1. Прогресс-бар на главном экране
- Отображает общий поднятый вес за день
- Показывает количество тренировок
- Переход к основному экрану активности по клику

### 2. Основной экран активности (`ActivityScreen`)
- Выбор даты для просмотра тренировок
- Навигация по дням с помощью стрелок
- Отображение статистики тренировок
- Список тренировок за выбранный день
- Создание новой тренировки

### 3. Создание тренировки (`CreateWorkoutScreen`)
- Выбор даты тренировки
- Указание продолжительности (необязательно)
- Выбор целевых групп мышц (необязательно)
- Быстрые варианты продолжительности (30, 45, 60, 90, 120 минут)

### 4. Детализация тренировки (`WorkoutDetailScreen`)
- Просмотр информации о тренировке
- Статистика: количество упражнений, общий вес, время
- Список упражнений с подходами
- Добавление новых упражнений
- Переход к управлению подходами
- Удаление тренировки

### 5. Выбор упражнений (`ExerciseSelectionScreen`)
- Поиск упражнений по названию
- Фильтрация по группам мышц
- Множественный выбор упражнений
- Пагинация для больших списков
- Добавление выбранных упражнений в тренировку

### 6. Управление подходами (`ExerciseSetsScreen`)
- Автоматическое создание 3 подходов по умолчанию
- Добавление/удаление подходов
- Редактирование количества повторений и веса
- Автоматический расчет общего веса подхода
- Учет количества снарядов при расчете веса
- Массовое сохранение подходов на сервере

## Модели данных

### Exercise
- `id`: Уникальный идентификатор
- `name`: Название упражнения
- `targetMuscleGroup`: Целевая группа мышц
- `equipmentCount`: Количество снарядов

### Workout
- `id`: Уникальный идентификатор
- `userId`: ID пользователя
- `date`: Дата тренировки
- `duration`: Продолжительность в минутах (необязательно)
- `targetMuscleGroups`: Целевые группы мышц
- `totalWeight`: Общий поднятый вес
- `exercises`: Список упражнений в тренировке

### WorkoutExercise
- `id`: Уникальный идентификатор
- `workoutId`: ID тренировки
- `exerciseId`: ID упражнения
- `exerciseName`: Название упражнения
- `targetMuscleGroup`: Группа мышц
- `equipmentCount`: Количество снарядов
- `totalWeight`: Общий вес всех подходов
- `sets`: Список подходов

### WorkoutSet
- `id`: Уникальный идентификатор
- `workoutExerciseId`: ID упражнения в тренировке
- `reps`: Количество повторений
- `weight`: Вес снаряда
- `totalWeight`: Общий поднятый вес (рассчитывается автоматически)

## API интеграция

Модуль использует `ActivityService` для взаимодействия с бэкенд API:

- **Упражнения**: получение списка, поиск, фильтрация по группам мышц
- **Тренировки**: создание, получение по дате, получение статистики, удаление
- **Упражнения в тренировке**: добавление упражнений в тренировку
- **Подходы**: создание, обновление, удаление, массовое создание

## Особенности реализации

### Оптимизация производительности
- Использование `RepaintBoundary` для изоляции перерисовок
- Кэширование данных с TTL
- Debounce для поисковых запросов
- Мониторинг производительности через `PerformanceMonitorMixin`

### Автоматические расчеты
- Общий вес подхода = повторения × вес снаряда × количество снарядов
- Общий вес упражнения = сумма весов всех подходов
- Общий вес тренировки = сумма весов всех упражнений

### Пользовательский опыт
- Интуитивная навигация между экранами
- Подсказки для пользователей
- Обработка ошибок с возможностью повтора
- Индикаторы загрузки
- Уведомления об успешных операциях

### Работа с ошибками
- Graceful handling ошибок сети
- Retry логика для HTTP запросов
- Fallback значения при ошибках загрузки
- Информативные сообщения об ошибках

## Интеграция с главным экраном

Модуль интегрирован в главный экран приложения (`MainScreen`):
- Добавлен прогресс-бар активности

- Обновление данных при возвращении с экранов активности
